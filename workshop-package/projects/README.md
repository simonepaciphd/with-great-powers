# Create your working folder here

Use `projects/` as the place where you make exactly one working project for the seminar.

## Option A - start from a provided example

1. Copy one of the shipped template folders:
   - `../toy-project-vdem/`
   - `../toy-project-anes/`
   - `../toy-project-qog/`
2. Paste the copy into `projects/`.
3. Rename the copy to something recognizable.
4. Open `workshop-package/` in Claude Code or Codex and run `/project-setup-existing` on that copied folder.

## Option B - start from your own assets

1. Create a new folder in `projects/`.
2. Put your dataset (or a manageable slice of it) in that folder.
3. If you already have one or two reference papers on the concept, put them there too.
4. Open `workshop-package/` in Claude Code or Codex and run `/project-setup` on that folder.

## Why this folder exists

The shipped `toy-project-*` folders are templates. Keeping your actual working copy in `projects/` makes it easy to restart if a demo goes sideways or if you want to try the same workflow on a second concept.

# Workshop skills

This folder holds the canonical playbooks for the seminar package.

## How to use them

- In **Claude Code**, open `workshop-package/` and use the matching slash command. The wrapper skill under `.claude/skills/` will point back here.
- In **Codex**, open `workshop-package/` and read the relevant file in this folder directly. `AGENTS.md` points here on startup.
- The files in this folder are the source of truth. Do not edit the Claude wrapper files unless you are changing the bridge itself.

## Setup and meta-skills

- `project-setup.md` - scaffold a brand-new participant folder from chosen assets.
- `project-setup-existing.md` - retrofit a copied toy project or another pre-existing folder.
- `skill-writing.md` - revise or rebuild a reusable local skill, usually `operationalize.md`.

## Measurement skills
